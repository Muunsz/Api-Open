# Api-Open

Open-source API client & testing platform (Hoppscotch / Postman style) built with:

- **Frontend (`apps/web`)**: Vue 3 + TypeScript + Vite + Pinia + Element Plus
- **Backend (`apps/api`)**: NestJS + TypeScript + Prisma ORM
- **Shared (`packages/shared`)**: Shared TypeScript types & contracts
- **Infrastructure**: Supabase (PostgreSQL) + Vercel (Frontend)

## Quick Start

```bash
# Install all workspace dependencies
npm install

# Run frontend dev server
npm run dev:web

# Run backend dev server
npm run dev:api
```
