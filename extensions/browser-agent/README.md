# Api-Open Browser Agent Extension

Allows Api-Open in the browser to execute requests against `localhost`, private LAN services, and third-party APIs without CORS errors.

## Installation (Chrome / Edge / Brave)

1. Open `chrome://extensions` (or `edge://extensions`).
2. Enable **Developer mode** (top-right).
3. Click **Load unpacked** and select this `extensions/browser-agent` folder.
4. Refresh Api-Open and switch Interceptor to **Browser**.
